FollowFrame / Windows

Privacy policy

FollowFrame is a local-first Windows desktop utility. It does not operate a FollowFrame account service or upload your Instagram login, media wall, or desktop diagnostics to a FollowFrame server.

Desktop app data

  • Instagram session: when you choose Connect account, Instagram loads in an embedded browser window. Session cookies and related browser storage remain in a persistent Electron partition for the current Windows user.
  • Followed content: the app reads media URLs and related display metadata from the followed Instagram pages loaded in that local session so it can build the wall. The app connects directly to Instagram and the content hosts used by Instagram.
  • Local preferences and cache: playback settings, window state, the current media queue, and capture diagnostics are stored in the app data folder for the current Windows user.
  • Runtime diagnostics: local event logs use safe item fingerprints and redact URL-like values. FollowFrame does not transmit these logs.
  • Optional active-use count: disabled by default. If you enable it in Settings, the app sends a random installation ID, FollowFrame version, and Windows/x64 at most once per day. It does not include an Instagram account, media, URLs, local paths, or diagnostics. Disabling the setting deletes the local anonymous ID.

How data is used

The desktop app uses this data only to keep you signed in to the embedded source session, capture the followed content you request, play the local wall, remember your settings, and diagnose local runtime behavior. FollowFrame does not sell personal information or use desktop-app data for advertising.

Retention and controls

Local settings, browser storage, cached wall data, and diagnostics remain on the Windows device until they are cleared. Use Logout in FollowFrame to clear the embedded Instagram session and wall cache. You can also remove remaining FollowFrame app data through Windows after uninstalling the app.

Website analytics

Followframe.com loads visitor-side Google Analytics only after you select Allow. When enabled, it records a page view and generic download, outbound-link, and support-link events. You can review or withdraw this choice through Analytics settings in the website footer.

The first-party download server separately reports a generic event after it finishes sending a complete FollowFrame EXE. It does not send the visitor's IP address, cookies, or a persistent visitor identifier to Google Analytics. Partial range requests and checksum downloads are not counted as completed downloads.

If desktop active-use sharing is enabled, the first-party server replaces the random installation ID with a one-way keyed pseudonymous identifier before sending an app_active event to Google Analytics. The server does not persist the submitted random ID.

External services

Instagram and PayPal process data under their own privacy terms when you use their services. FollowFrame is independent and is not affiliated with, endorsed by, or sponsored by Instagram or Meta.

Policy questions

For privacy or support questions, use the current project and release information maintained at followframe.com.
