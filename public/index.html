Short notes.

Is FollowFrame for Instagram?

Yes. FollowFrame is built for viewing Instagram posts, Reels, photos, videos, and Stories from accounts you follow in a floating Windows desktop frame.

Do I need Node.js or an installer?

No. The public download is a single Windows x64 executable.

Will Windows warn on first launch?

It may. The current build is a portable Electron executable and can show an unsigned-app warning.

Does the app include an Instagram account?

No. First launch on a new Windows user needs a local Instagram login inside the app.

Is FollowFrame affiliated with Instagram or Meta?

No. FollowFrame is an independent desktop utility and is not affiliated with, endorsed by, or sponsored by Instagram or Meta.

What does the website analytics collect?

With permission, the site records a page view plus generic download/support click events. The download server also counts completed full EXE responses without cookies or visitor identifiers. Neither path sends Instagram account names, media URLs, or local paths. Website analytics permission can be reviewed or withdrawn at any time from Analytics settings in the footer.

Does the desktop app share usage statistics?

Not by default. An optional setting can share one anonymous active-use heartbeat per day using a random app ID, the FollowFrame version, and Windows/x64. It never includes an Instagram account, media, URLs, local paths, or diagnostics, and disabling it deletes the local anonymous ID.
