FollowFrame / privacy

Local source sessions. Minimal public signals.

FollowFrame is designed to avoid collecting account identities, private media, browser profiles, source URLs, local paths, or diagnostics through the public website.

Desktop sources

The Personal Instagram connector stores its session in the current Windows user's Electron data directory. Local-folder sources store their selected root and derived playback metadata on that device. Files are not copied or uploaded by FollowFrame.

Optional active-use statistics

Disabled by default. If enabled, the app sends a random installation ID, app version, Windows, and x64 at most once per day. The server HMAC-pseudonymizes the ID for deduplication and never stores the raw ID, IP address, user agent, account identity, media, URL, local path, or diagnostics.

Pseudonymous daily deduplication digests are deleted after 45 days. Non-identifying daily aggregates are retained for up to 24 months.

Website analytics and downloads

Consent-gated analytics records page views and generic product exploration, download, support, and sponsor actions. The download server keeps daily aggregate EXE and checksum delivery starts, completions, failures, and interruptions; these totals are not counts of people or installations.

Contact

Privacy questions can be sent to support@followframe.com. Support emails are used only to answer the message and maintain necessary correspondence.
