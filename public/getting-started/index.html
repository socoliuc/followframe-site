FollowFrame / first run

From download to a calmer desktop.

FollowFrame is a portable Windows app. There is no cloud account, companion service, or bundled Instagram login.

Install and verify

  1. Download the current Windows x64 EXE from FollowFrame.
  2. Optionally compare its SHA-256 checksum with the value on the download page.
  3. Open the portable app. Windows may show a reputation prompt while the current release remains unsigned.

Choose a source

Personal Instagram is the original, experimental connector. Sign in only inside FollowFrame's private source window; the session stays on this Windows user account.

Local folders are the first source-independent option. Select a folder of supported images or videos, then choose it as the active source.

Set your pace

Choose refresh timing, photo duration, sound, start-on-login, and always-on-top behavior in Settings. The app plays one active source at a time.
