Current release

Version 0.3.9 · Windows x64 · Windows 10 · 93.0 MB.

This release makes cached startup immediate, keeps refresh capture hidden, restarts playback at the newest item after manual refresh, and filters the wall against the complete followed-account list.

How updates work

FollowFrame checks the public release record at most once per day without sending an installation identifier. Updates remain manual: review the notes, download the new EXE, and verify its checksum.
